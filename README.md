## How to study each topic

1. Learn the definition and purpose.
2. Understand each symbol in the equation.
3. Practise writing the algorithm/flowchart from memory.
4. Work through one small example.
5. Revise the comparison tables and short-answer questions.

## Long-answer writing format

For a 10-mark answer, use: **definition → explanation → mathematical equation → algorithm/diagram → example or advantages → conclusion**. For 5 marks, focus on definition, core explanation and the key equation.

## Important note

These notes are organized from the course syllabus and question lists shared for exam preparation. Check notation and exact expectations against your faculty's class notes and prescribed textbook, especially where a course may use a different reward or transition convention.
